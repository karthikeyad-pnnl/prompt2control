Block that determines the operation mode and availability of multiple heat pumps for heating, cooling, or simultaneous heating-cooling operation. It supports both 2-pipe and 4-pipe air-source heat pumps (ASHPs), and generates staging signals based on configurable matrices. The block also handles primary pump enabling for 4-pipe ASHPs and optional runtime-based lead-lag sorting.

Typical use and important parameters

Connect u1EnaHea to the heating plant enable signal, u1EnaCoo to the cooling plant enable signal, and uMod to the binary mode signal for 2-pipe HPs (true for heating, false for cooling). Set u1Hp to the vector of HP enable signals. For 4-pipe ASHPs, connect u1PumPriHea and u1PumPriCoo to the respective primary pump enables.

Set nHp to the number of heat pumps, is_fouPip to a vector indicating 4-pipe ASHPs, and has_sort to enable runtime-based sorting of lead-lag equipment. Configure staEquCooHea for the staging matrix in heating-cooling mode and staEquOneMod for heating-only or cooling-only modes, where each row specifies the equipment required per stage.

Implementation

The block first checks if both heating and cooling plants are enabled using an and gate (and2). If true, it sets the heating-cooling mode flag yHeaCoo and selects the staging matrix staEquCooHea via a switch (swi). Otherwise, it uses staEquOneMod for single-mode operation.

For 2-pipe HPs, the mode signal uMod is converted to an integer and replicated across all HPs to produce yMod. For 4-pipe ASHPs, latches (lat, lat1) maintain heating-only or cooling-only states based on plant enables and pump signals, triggered by falling edges of HP enables (falEdg). Availability outputs yAvaFouPipHea and yAvaFouPipCoo are set true only for enabled 4-pipe HPs in the respective modes. The primary pump enable y1PumPri activates when any 4-pipe primary pump is on and heat recovery HPs are in heating-cooling mode (and9).

Staging indices yIdxSta are generated without sorting by switching between direct (conInt1) and reverse (conInt2) orders if has_sort=false. The final staging matrix yStaEqu outputs the selected equipment requirements per stage. Mode equalities (intEqu, intEqu1, intEqu2) and logical combinations ensure proper mode detection and availability only for enabled, heat-recovery-capable HPs. Algebraic loops are broken using pre operators (pre, pre1, pre2).
